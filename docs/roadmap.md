# Roadmap

## Phase 1 (current)
- Core CRM: leads, tasks, notes
- Generic dialer integration via adapter
- Compliance spine: pre-call checks, SOA capture, disclosures, outbound enrollment verification
- Audit logging for key events
- Seed data and docker-compose for local stack

## Phase 2 (future)
- Advanced reporting and dashboards
- State-specific rule engines and configurable compliance policies
- Additional integrations (Supabase auth, multiple dialers, carrier systems)
- Agent performance analytics and QA tooling
- Real-time event streaming and alerting
